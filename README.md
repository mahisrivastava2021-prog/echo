# Echo

> **Work in progress.** This is a demo, not legal advice.

Echo is a multilingual, mobile-first web app for migrant domestic workers in Singapore. A worker describes her situation by voice or text, and Echo:
- explains her rights using official Ministry of Manpower (MOM) rules, citing the source for each answer;
- flags how serious the situation is;
- keeps a private, encrypted, on-device journal;
- connects her to help.

It is a portfolio project that grew out of a Create4good 2026 concept. The live demo and full documentation are coming soon.
